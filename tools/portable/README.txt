【怎么用】
  双击本目录里的  start.cmd  即可。
  程序会自动启动本地服务并打开浏览器；关闭黑色命令窗口即结束。

  如果浏览器没有自动打开，请在浏览器地址栏手动输入窗口里显示的地址
  （形如 http://127.0.0.1:5173/ ）。

【环境要求】
  无需安装 Node.js、无需联网。
  Windows 10 / 11 64 位即可。首次打开时若出现防火墙提示，
  选择「允许访问」或直接关闭（本服务只监听 127.0.0.1，不对外网开放）。

【目录说明】
  start.cmd            启动入口（双击这个）
  server.mjs           本地服务程序（零依赖，纯 Node 内置模块）
  runtime/node.exe     便携 Node 运行时（约 80MB）
  web/                 网站本体（页面、脚本、数据 JSON）
  images/thumbs/       卡面缩略图（列表页使用）
  images/full/         卡面原图（若存在则详情页显示大图）

【常见问题】
  1) 端口被占用？
     程序会自动从 5173 往后找空闲端口，无需手动处理。
  2) 卡面大图模糊？
     极简版只打包了缩略图，详情页会自动用缩略图代替原图。
     把完整卡面（chr51 目录）放到 images/full/chr51/ 下即可恢复高清。
  3) 换电脑后数据不更新？
     数据来自 web/data/ 下的 JSON；更新数据需要重新生成后替换该目录。
